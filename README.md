# VocalPlus Academy — Client

A modern music school management platform built with React, Tailwind CSS, and Framer Motion.

## Tech Stack
- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Zustand
- Axios
- React Router v6
- React Hot Toast

## Features
- Landing page with animations
- Student authentication (Email + Google OAuth)
- Student dashboard
- Admin dashboard
- Course listings
- Enrollment management

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables
Create a `.env` file:

## VITE_API_URL=http://localhost:5000
